🛡️ Core Safety Guarantees

      
Built from the ground up for strict data preservation and zero photo loss.

    


    

      

        
🔒

        
Non-Destructive Copying

        
The CLI is strictly copy-first. It never deletes or moves your original photos or source files.

      

      

        
⚡

        
Streaming SHA-256 Checksums

        
Every single photo and video is verified using streaming SHA-256 hashes before and after copying to guarantee bit-for-bit integrity.

      

      

        
📅

        
Preserves Sidecars & Dates

        
Uses shutil.copy2 to preserve exact file modification dates and automatically copies associated sidecars (.xmp, .aae, .json).

      

      

        
🍏

        
Apple Photos Safety Rule

        
Never scans internal .photoslibrary packages directly. Exports unmodified originals first to an external staging volume to prevent library corruption.

      

    

  


  
  

    

      
🚀 The 4-Step Archiving Pipeline

      
How photo-archive organizes and backs up your library onto external storage.

    


    

      

        
01

        
Export Originals

        
Export unmodified originals from Apple Photos or Lightroom onto an external staging volume.

      

      

        
02

        
Scan & Hash

        
Run photo-archive scan to build a SHA-256 manifest and CSV summary of all files.

      

      

        
03

        
Copy to Archive

        
Run photo-archive copy to non-destructively organize files into category folders.

      

      

        
04

        
Verify Integrity

        
Run photo-archive verify to confirm 100% checksum match on the destination drive.
