Architecture & Safety

      
Core Safety Guarantees

      
Built from the ground up for strict data preservation and zero photo loss.

    


    

      

        
🔒

        
Non-Destructive Copying

        
The CLI is strictly copy-first. It never deletes or alters your original photos or source files.

      

      

        
⚡

        
Streaming SHA-256 Checksums

        
Every photo and video is verified using streaming SHA-256 hashes before and after transfer to guarantee bit-for-bit integrity.

      

      

        
📅

        
Preserves Sidecars & Dates

        
Uses shutil.copy2 to preserve exact creation/modification dates and automatically copies associated sidecars (.xmp, .aae, .json).

      

      

        
🍏

        
Apple Photos Safety Rule

        
Never scans internal .photoslibrary packages directly. Exports unmodified originals first to an external staging volume to prevent library corruption.

      

      

        
👯

        
Idempotent Duplicate Prevention

        
Re-running copy safely skips existing archive files with matching size and SHA-256 hash, preventing storage waste.

      

      

        
🛡️

        
Atomic Manifest Auditing

        
Generates JSON manifests and CSV reports of all scanned, copied, and verified files before taking action for complete transparency.

      

    

  


  
  

    

      
Execution Pipeline

      
The 4-Step Archiving Pipeline

      
How photo-archive organizes and backs up your library onto external storage.

    


    

      

        
01

        
Export Originals

        
Export unmodified originals from Apple Photos or Lightroom onto an external staging volume.

      

      

        
02

        
Scan & Hash

        
Run photo-archive scan to build a SHA-256 manifest and CSV summary of all files.

      

      

        
03

        
Copy to Archive

        
Run photo-archive copy to non-destructively organize files into category folders.

      

      

        
04

        
Verify Integrity

        
Run photo-archive verify to confirm 100% checksum match on the destination drive.

      

  
  

    

      
Manual & Terminal Walkthrough

      
Step-by-Step Instructions

      
Follow these exact step-by-step instructions to manually export, scan, copy, and verify your photo library.

    


    

      
      

        
STEP 01

        
🍏 Export Unmodified Originals from Apple Photos

        
To prevent library database corruption, never scan .photoslibrary packages directly. Always export unmodified originals to a staging folder on your external drive first:

        
    
          
  1. Open the Photos app on your Mac.
    2. 
          
  2. Confirm originals are downloaded: Photos → Settings → Download Originals to this Mac.
    3. 
          
  3. Select the photos/albums you want to archive.
    4. 
          
  4. Go to File → Export → Export Unmodified Original for Photos...
    5. 
          
  5. Ensure Export IPTC as XMP is enabled.
    6. 
          
  6. Choose an external staging folder (e.g. /Volumes/MyPassport/_export_staging/2026-icloud-export).
    7. 
        

      


      
      

        
STEP 02

        
⚡ Install CLI & Build SHA-256 Manifest

        
Install the toolkit and run photo-archive scan against your staging folder or external drive to generate a SHA-256 inventory:

        

          
# 1. Install CLI locally
python3 -m pip install -e .

# 2. Run Scan against your exported staging folder
photo-archive scan \
  --source-root "/Volumes/MyPassport/_export_staging/2026-icloud-export" \
  --source-class icloud-export \
  --batch-name "2026-07-icloud-photos" \
  --manifest-out "./manifests/icloud-scan.json" \
  --csv-out "./manifests/icloud-scan.csv"

        

      


      
      

        
STEP 03

        
👯 Run Dedupe Audit & Non-Destructive Copy

        
Check for exact duplicate files across your backup sources, then execute the non-destructive copy to your primary archive drive:

        

          
# 1. Audit exact SHA-256 duplicate files
photo-archive dedupe-report \
  --manifest "./manifests/icloud-scan.json" \
  --report-out "./manifests/duplicates.json"

# 2. Execute non-destructive copy to target archive drive
photo-archive copy \
  --manifest "./manifests/icloud-scan.json" \
  --archive-root "/Volumes/MyPassport/Photo Archive" \
  --report-out "./manifests/copy-report.json"

        

      


      
      

        
STEP 04

        
🛡️ Verify 100% SHA-256 Checksum Integrity

        
Re-calculate streaming SHA-256 hashes on the target external hard drive to guarantee bit-for-bit file integrity:

        

          
# Run complete checksum verification
photo-archive verify \
  --manifest "./manifests/icloud-scan.json" \
  --archive-root "/Volumes/MyPassport/Photo Archive" \
  --report-out "./manifests/verify-report.json"
